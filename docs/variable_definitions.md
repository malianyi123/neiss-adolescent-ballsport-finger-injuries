# Variable Definitions

Derived variables:

- `age_group`: 10-12, 13-15, 16-18.
- `sex_clean`: male, female, unknown/other.
- `diagnosis_group`: fracture or dislocation.
- `sport_group`: basketball, football, baseball/softball, soccer, volleyball, or other selected ball sports when the combined category has sufficient sample size.
- `disposition_group`: treated/released, transferred, admitted, observation, other/unknown.
- `severe_disposition`: 1 for admitted, transferred, observation, or fatality; 0 for treated/released; missing otherwise.
- `calendar_period`: pre-pandemic (2015-2019), pandemic (2020-2021), post-pandemic (2022-2025).
- `season`: winter, spring, summer, fall.
- `narrative_mechanism`: conservative keyword class for narrative descriptions. Because narrative length changed in 2019, this variable is descriptive only and is emphasized for 2019-2025.
